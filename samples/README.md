# Sample Artifacts

This directory contains synthetic sample files for the insurance-claims-ai-pipeline lab.
All files are generated or hand-written for demonstration purposes only.

## Files

| File | Type | Used by |
|------|------|---------|
| `manifest.json` | Manifest | Triggers the pipeline via EventBridge |
| `photo-damage.jpg` | Image (JPEG) | Rekognition DetectLabels |
| `police-report.pdf` | Document (single-page PDF) | Textract AnalyzeDocument |
| `statement.txt` | Text (UTF-8) | ReadText Lambda -> Bedrock |

## red-flag/

Same structure as above but with a statement that contains multiple red-flag signals
(no police report, vague incident details, coverage increase 2 weeks prior, damage
inconsistent with stated cause). Use this set in S7 to observe the guardrail
downgrading the LLM recommendation to NEEDS_REVIEW.

## Photo requirements

The included `photo-damage.jpg` is a minimal placeholder JPEG (structurally valid,
accepted by Rekognition, but contains no meaningful visual content).

For a meaningful Rekognition demo, replace it with a real vehicle damage photograph:
- Use your own photograph, or
- Use a CC0/public-domain image (e.g., Unsplash, Wikimedia Commons)
- Document the source and license in this README before committing

Rekognition DetectLabels constraints for this pipeline:
- Format: JPEG or PNG
- Maximum size: 5 MB
- Minimum dimension: 80x80 pixels recommended

## PDF requirements

The included `police-report.pdf` is a synthetic single-page PDF generated by
`generate-samples.py`. It is accepted by Textract AnalyzeDocument (sync, single-page).

**IMPORTANT**: Textract AnalyzeDocument (synchronous) accepts only single-page PDFs
or PNG images. Multi-page PDFs require the asynchronous StartDocumentAnalysis API.
See guide.md Appendix D for the extension exercise.

PDF constraints for this pipeline:
- Single page only
- Format: PDF or PNG
- Maximum size: 5 MB
